# 中国财政沙盘

把四张财政图做成一台可以拧旋钮的机器：

| 图 | 内容 | 在沙盘里 |
| --- | --- | --- |
| ① 中国公共债务的构成与规模 | 国债、地方债、城投隐性债务（多口径） | 「债务」页：按比例的债务积木、口径对比、存量-流量、利息账 |
| ② 2026 年全国一般公共预算安排 | 中央/地方收入、赤字、调入、转移支付、本级支出 | 「2026 预算」页：资金流向桑基图 + 三条预算恒等式 |
| ③ 2025 年全国一般公共预算执行 | 16 个税种、出口退税、非税收入、13 类支出、差额 | 「2025 执行」页：桑基图 + 分税制拆分 |
| ④ 财政"四本账"（2021） | 一般预算、政府性基金、国有资本经营、社保基金 | 「四本账」页：账本之间的调入调出、补贴、合并口径广义赤字 |

另有「十年推演」（债务动态、全口径付息、长期收敛负债率、不确定性扇形图）、「影响与敏感度」（影响矩阵、双参数相图、龙卷风图、反向求解）、「挑战」（7 个关卡、13 道先猜后算、12 张事件卡）、「公式手册」（名词、方法与局限、公式实验室、全部公式、跨图连接、假设清单、原图对账），以及总览页的 6 条讲解、情景 A/B 对比与情景代码。完整公式清单见 [docs/MODEL.md](docs/MODEL.md)（自动生成）。

直接打开 `dist/index.html` 即可使用（单文件，无需安装）。

## 它怎么保证"每个变化都有正确公式"

- **公式即计算。** 每个派生量是一条表达式字符串，例如 `rc25 * (1 + g_rc + eps * (g_nom - g_nom0))`。同一棵语法树既用来求值，也用来渲染公式卡片的「公式 / 读法 / 拟音 / 代入」四行，所以显示的公式不可能和实际算法不一致。
- **基线 = 原图。** 默认参数取自四张图，`tests/reconcile.test.mjs` 逐项核对原图上的 107 个数字（界面里「公式手册 → 原图对账」可以看到同一张表）。
- **恒等式随机测试。** `tests/identities.test.mjs` 在 300 组随机参数 × 随机平衡规则下检查全部会计恒等式（预算平衡、存量-流量、四本账合并、债务动态分解）。
- **公式分三类并标注。** 会计恒等式（图中直接成立）、校准关系（参数由图中数字反推，如国债平均付息率 = 8,739.90 ÷ 412,300）、假设关系（图中没有、为连接各图引入，如地方债利率 2.8%），全部可调。

## 四张图怎么连起来

| 连接 | 公式 |
| --- | --- |
| ③ → ② 收入基数 | 2026 预算收入 = 2025 执行数 × (1 + 预算增速 + ε × 名义增速偏离) |
| ③ → ② 国防 | 2026 国防 = 2025 国防（图③，全在中央本级）× 1.07 |
| ③ → ① 反事实 | 期初国债 = 图①国债 + (2025 中央赤字 − 实际值) |
| ② → ① 新增债务 | 年末国债 = 期初 + 中央赤字 + 特别国债；一般债 + 地方赤字；专项债 + 新增专项债 + 置换 |
| ① → ② 付息 | 中央付息 = 国债平均付息率 × 国债余额 |
| ④ ↔ ②③ | 实际赤字 = 支出 − 收入 = 预算赤字 + 调入资金 − 补充稳定基金 |
| ②① → 推演 | Δd = d₋₁ · (r − g) / (1 + g) + 基本赤字率 + 其他债务融资率（精确恒等式） |

## 帮你看懂传导的工具

- **传导回放**（总览页）：按依赖图的拓扑顺序，一站一站点亮变化经过的图和箭头，每站给出箭头上的公式和变化量。
- **公式卡片**：点任何数字，看"公式 / 读法 / 拟音 / 代入"、由谁决定、影响谁；有变化时还会给出逐项贡献和主要传导路径，并能"在图上找到它"。
- **传导链**：一句话总结 + 按依赖顺序列出每个被牵动的数字（或切换为路径图）；"复制本次分析"把改动、规则、关键结果的代入式和情景代码复制成纯文本。
- **规则对比表**（2026 预算页）：同一组改动放到六种平衡规则下，看每种规则由谁接住冲击。
- **影响矩阵**：15 个关键旋钮 × 13 个关键结果，"·"表示没有公式路径，"0"表示有路径但相互抵消。
- **双参数相图**：两个旋钮一起拧，31 × 31 格逐格重算。等值线的形状说明两者能否相加；给出取舍比率 Δy = −(∂f/∂x·Δx) ÷ (∂f/∂y·Δy₁) × Δy₁ 和交互项 I = f(x₁,y₁) − f(x₁,y₀) − f(x₀,y₁) + f(x₀,y₀) 的代入式；点任意一格即可把两个参数设过去。
- **反向求解**：想让某个指标达到目标，只调一个参数要调到多少（二分法，限定在滑杆允许区间内）。

## 平衡规则

预算恒等式里必须有一项是余项。模拟器让你选择由谁兜底：

- 2025：赤字锁定（调入资金兜底）/ 调入锁定（赤字兜底）/ 支出调整（"其它"支出兜底）
- 2026 中央：赤字率锚定（支出兜底，吸收项可选"本级其它"、"转移支付"或"本级各项等比例"）/ 支出锚定（赤字兜底）/ 稳定基金兜底
- 2026 地方：以收定支 / 支出锚定（调入资金兜底）
- 四本账：预算赤字锁定 / 其他支出锁定；政府性基金"计划支出 + 不列赤字" / 以收定支；社保补贴固定 / 补贴兜底
- 推演：赤字率不变 / 支出增速不变

切换规则本身不改变任何当前数字（有测试保证），只改变之后由谁吸收冲击。

## 开发

```bash
npm install          # esbuild、playwright（仅开发用）
npm test             # 单元测试：引擎、对账、恒等式、关卡可解、测验答案
npm run build        # 打包 dist/index.html 与 dist/artifact.html
npm run e2e          # 浏览器端到端测试（需先 build）
npm run serve        # 本地预览源码版 http://localhost:5173/
```

目录：

```
src/engine/   表达式解析、依赖图、拓扑求值
src/model/    原图数据、全部节点规格、平衡规则、对账表、关卡与测验
src/ui/       界面：外壳、参数面板、公式卡片、传导链、各页视图、图表
tests/        单元测试与端到端测试
docs/PLAN.md  开发大纲
```

## 数据与局限

- 数据来自四张图（公众号"微言书"，梦游尘制图），2025/2026 年数字对应财政部 2026 年 3 月向全国人大提交的预算报告，四本账为 2021 年决算。
- 图中没有给出的量（名义 GDP、一般债/专项债拆分、利率、土地出让收入占政府性基金的比例等）以"假设"或"校准"参数引入，并在「公式手册 → 假设清单」逐条列出依据。
- 四本账使用 2021 年数据，与 2025/2026 年模块不直接相加，用于演示账本之间的机制。
- 这是理解机制的教学工具，不是预测模型：行为关系（如收入弹性、利率重定价速度）都做了简化。
