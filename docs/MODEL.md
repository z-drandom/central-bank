## 平衡规则

- **2025 平衡规则**（默认：赤字锁定）
  - 赤字锁定：赤字是人大批准的数；收支变化由"调入资金"吸收（动用结转结余、稳定调节基金）
  - 调入锁定：调入资金不变；收支变化全部反映为赤字（反事实：如果当年多借/少借）
- **中央平衡规则**（默认：赤字率锚定）
  - 赤字率锚定：先定赤字率，中央支出 = 收入 + 赤字 + 调入，由"吸收项"承担增减
  - 支出锚定：支出各项先定，中央赤字 = 支出 − 收入 − 调入（赤字率随之变化）
  - 稳定基金兜底：赤字率和支出都定死，缺口从中央预算稳定调节基金调入
- **中央吸收项**（默认：本级"其它"支出）
  - 本级"其它"支出：中央支出增减由中央本级"其它"支出承担（挤出效应最直观）
  - 对地方转移支付：中央支出增减由转移支付承担，进而传到地方支出
- **地方平衡规则**（默认：以收定支）
  - 以收定支：地方支出 = 地方收入 + 转移支付 + 地方赤字 + 调入资金
  - 支出锚定：地方支出按增速先定，缺口由"调入资金及使用结转结余"补
- **隐性债务口径**（默认：官方口径）
  - 官方口径：官方披露 2024 年末隐性债务 10.5 万亿
  - 城投有息债务：城投债券 + 其它有息负债（笔者估算）
  - 宽口径：城投债券 + 其它有息负债 + 其它负债（图①上限口径）
- **第一本账规则**（默认：预算赤字锁定）
  - 预算赤字锁定：赤字由人大批准；支出 = 总收入 + 赤字 − 补充稳定基金，补贴增加会挤占其他支出
  - 其他支出锁定：其他支出不变；补贴、调入变化反映为预算赤字
- **第二本账规则**（默认：计划支出 + 不列赤字）
  - 计划支出 + 不列赤字：按计划支出，但支出不能超过收入总量（不列赤字），差额被迫压减
  - 以收定支：支出 = 收入总量 × 支出率
- **第四本账规则**（默认：补贴固定）
  - 补贴固定：财政补贴不变，社保基金结余随收支变化
  - 补贴兜底：财政补贴 = 支出 + 目标结余 − 其他收入，缺口由一般公共预算补
- **推演规则**（默认：赤字率不变）
  - 赤字率不变：每年赤字 = 赤字率 × GDP；付息增加挤占非付息支出
  - 支出增速不变：非付息支出按固定增速增长；赤字 = 支出 − 收入 − 调入

#### 稳定调节基金净增加（会计恒等式）

```
公式：ΔS = S_in − S_out
读法：稳定调节基金净增加 = 稳定调节基金流入 − 稳定调节基金流出
拟音：Δ 读"德尔塔"
代入：ΔS = 0.47 − 0.30 = 0.17 万亿元
```

#### 一般公共预算支出（会计恒等式）

```
公式：E_1 = R^tot_1 + D_1 − S_1
读法：一般公共预算支出 = 一般公共预算总收入 + 预算赤字 − 补充中央预算稳定调节基金
代入：E_1 = 21.37 + 3.57 − 0.36 = 24.58 万亿元
```

#### 广义赤字（按融资来源分解）（会计恒等式）

```
公式：A^all = D_1 + B_s + C_1 + C_2 + C_3 − (C'_2 + C'_3) − ΔS − S_4
读法：广义赤字（按融资来源分解） = 预算赤字 + 地方专项债 + 一般公共预算结转结余资金 + 政府性基金上年结转收入 + 国有资本经营上年结转 − (政府性基金结转下年 + 国有资本经营结转下年支出) − 稳定调节基金净增加 − 社保基金当年结余
拟音：Δ 读"德尔塔"
代入：A^all = 3.57 + 3.65 + 0.13 + 0.02 + 0.04 − (1.61 + 0.00) − 0.17 − 0.99 = 4.64 万亿元
```

恒等式：广义赤字 = 预算赤字 + 专项债 + 动用上年结转 − 结转下年 − 稳定基金净增加 − 社保当年结余。两种算法结果必然相等。

#### 其他一般公共预算支出（会计恒等式）

```
公式：E^o_1 = E_1 − T_1→4 − T_1→2
读法：其他一般公共预算支出 = 一般公共预算支出 − 财政对社保基金补贴 − 一般公共预算调入政府性基金
代入：E^o_1 = 24.58 − 2.30 − 0.02 = 22.26 万亿元
```

扣掉给其他账本的钱之后，真正花在一般公共服务上的支出。

#### 一般公共预算支出总量（会计恒等式）

```
公式：E^tot_1 = E_1 + S_1
读法：一般公共预算支出总量 = 一般公共预算支出 + 补充中央预算稳定调节基金
代入：E^tot_1 = 24.58 + 0.36 = 24.94 万亿元
```

#### 实际赤字（会计恒等式）

```
公式：A_1 = E_1 − R_1
读法：实际赤字 = 一般公共预算支出 − 一般公共预算收入
代入：A_1 = 24.58 − 20.26 = 4.32 万亿元

实际赤字 = 支出 − 当年收入，不扣调入资金。它比预算赤字大，差额是"调入资金 − 补充稳定基金"。

```
