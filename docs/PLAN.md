# 财政沙盘 · 开发大纲

目标：把四张图（①公共债务构成与规模 ②2026 年一般公共预算安排 ③2025 年一般公共预算执行 ④财政"四本账"）做成一个联动模拟器。
任何一个数字都能点开看到「公式 / 读法 / 代入」，调任何参数都能看到沿依赖图传导的全部变化。

## 设计原则

1. **公式即计算**：每个派生量用一条表达式字符串定义（如 `rc25 * (1 + g_rc)`），同一条表达式既用于求值，也用于渲染成公式卡片。显示的公式不可能与实际算法不一致。
2. **基线 = 原图**：所有输入参数的默认值取自四张图；单元测试逐项核对原图数字（见 `tests/reconcile.test.mjs`）。
3. **公式分级**：每条公式标注性质——`会计恒等式`（图中直接成立的加总关系）、`校准关系`（参数由图中数据反推）、`假设`（图中没有、需要外部假设的参数，均可调）。
4. **平衡规则可切换**：预算恒等式里必须有一项是"余项"。模拟器让用户选择由谁兜底（赤字、支出、调入资金……），切换规则不改变当前数值，只改变之后谁来吸收冲击。

## 模块

| 模块 | 对应图 | 年份 | 内容 |
| --- | --- | --- | --- |
| 2025 执行 | 图③ | 2025 | 16 个税种 → 税收 → 扣出口退税 → +非税 → 收入；13 类支出；差额 = 赤字 + 调入；分税制拆出中央/地方收入 |
| 2026 预算 | 图② | 2026 | 中央收入 + 中央赤字 + 调入 = 中央支出 = 本级 + 转移支付 + 预备费；地方收入 + 转移支付 + 地方赤字 + 调入 = 地方支出；赤字率 |
| 债务 | 图① | 2025 末 → 2026 末 | 国债、地方一般债/专项债、城投隐性债务三种口径；新增债务、置换化债、付息 |
| 四本账 | 图④ | 2021 | 一般公共预算、政府性基金、国有资本经营、社保基金之间的调入调出、补贴、稳定调节基金；合并口径广义赤字 |
| 十年推演 | ②+① | 2026–2035 | 债务动态 Δd = d·(r−g)/(1+g) + 基本赤字率 + 其他债务融资 |

跨图连接（全部是公式）：

- ③→②：2026 预算数 = 2025 执行数 × (1 + 增速)；国防支出直接取图③的 2025 值。
- ③→①：2025 年赤字偏离实际值时，2025 年末债务余额同步偏离（反事实调整）。
- ②→①：2026 年末余额 = 期初 + 中央/地方赤字 + 专项债 + 特别国债 + 置换。
- ①→②：中央债务付息 = 国债平均付息率 × 国债余额。
- ④↔②③："调入资金"来自其他三本账；预算赤字与实际赤字的区别。
